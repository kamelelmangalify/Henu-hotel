# 📱 دليل صياغة رسائل الواتساب للموظفين
## هوستل الأهرامات — نظام التسجيل الآلي

> **مهم:** الرسالة الصحيحة = تسجيل فوري في النظام + رد تأكيد خلال ثوانٍ

---

## 📌 النوع الأول: دخول نزيل (Check-In)

**الشكل الأساسي:**
```
دخول نزيل: [الاسم]، غرفة [رقم]، [عدد] ليلة/ليالٍ، [طريقة دفع]، [المبلغ] جنيه
```

**أمثلة صحيحة ✅:**
```
دخول نزيل: أحمد محمد، غرفة 12، 3 ليالي، نقد، 900 جنيه
```
```
تسجيل: سارة علي، غرفة 7، ليلة واحدة، شبكة، 500 جنيه
```
```
check in: John Smith, room 15, 2 nights, cash, 1200 EGP
```

**ملاحظات:**
- "نقد" أو "كاش" أو "cash" → يُسجَّل على Main Cash
- "شبكة" أو "POS" أو "كارت" → يُسجَّل على POS Cash
- "تحويل" أو "transfer" → يُسجَّل كتحويل بنكي
- المبلغ يُفترض أنه **شامل VAT 14%** — إذا كان بدون ضرائب، أضف: "بدون ضريبة"

---

## ☕ النوع الثاني: تقفيل وردية الكافيه

**الشكل الأساسي:**
```
تقفيل [الكافيه/المطعم]: إجمالي [المبلغ] جنيه [طريقة دفع]
```

**أمثلة صحيحة ✅:**
```
تقفيل كافيه المساء: إجمالي 2850 جنيه
```
```
إغلاق وردية الكافيه الصباحية: 1200 جنيه نقد + 800 جنيه شبكة
```
```
مبيعات المطعم الليلية: 4300 جنيه
```

**ملاحظات:**
- النظام يوزع تلقائياً: صافي إيراد + VAT 14% + رسم خدمة 12%
- اذكر الوردية (صباحية/مسائية/ليلية) للتوثيق

---

## 🧾 النوع الثالث: فاتورة مشتريات/مصروف

### الطريقة الأولى: رسالة نصية
```
فاتورة [اسم المورد]: [المبلغ] جنيه، [نوع الخدمة]
```

**أمثلة صحيحة ✅:**
```
فاتورة مغسلة النيل: 350 جنيه، غسيل بياضات
```
```
فاتورة صيانة: مؤسسة الوطني للكهرباء، 1200 جنيه
```
```
مصروف: 5 كيلو أرز من محمد للبقالة، 85 جنيه
```

### الطريقة الثانية: صورة الفاتورة 📸
**فقط أرسل صورة الفاتورة مباشرة** — سيقرأها النظام تلقائياً!

**للحصول على أفضل نتائج:**
- الإضاءة جيدة
- الكاميرا ثابتة
- الفاتورة كاملة في الإطار

**ملاحظات WHT:**
- مشتريات عادية → خصم 1% تلقائياً
- صيانة/خدمات/مقاولين → خصم 3% تلقائياً

## ❌ أمثلة خاطئة (ستطلب إعادة الصياغة)

| الرسالة الخاطئة | السبب | الصحيح |
|---|---|---|
| "دخل حد النهارده" | لا يوجد مبلغ ولا غرفة | "دخول نزيل: ..." |
| "الكافيه عمل كويس" | لا يوجد مبلغ | "تقفيل كافيه: إجمالي ..." |
| "اشترينا حاجة" | لا يوجد مورد ولا مبلغ | "فاتورة [اسم]: [مبلغ] جنيه" |
| صورة غير واضحة | يتعذر قراءة الأرقام | أعد التصوير في إضاءة أفضل |
